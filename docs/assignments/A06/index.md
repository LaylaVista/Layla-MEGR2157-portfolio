# A6 – Bracket Drawing

## Objective

Parametrically model the bracket from A5 in SolidWorks. Create a fully dimensioned multiview drawing of the part with engineering tolerances.

## Decide

For this assignment, I could choose to either model my part based on the strength dimensions or the stiffness dimensions. I decided to model my part based on the strength dimensions

## Reflections

- For the majority of my strength calculations, I used the equation A = F*SF/Sy. For example, for part D, I used width = (F * SF/Sy) / height to find the width. At one point, I went back and edited the equation for the width of D, and when the equation changed, the value on the model changed to match the new value, without me having to manually change it.
- I put a tighter tolerance on the length of part E because the given value of the Rigid T Beam was to the fourth decimal place, while the other dimensions were to only three decimal places. I placed looser dimensions on my calculated values (e.g., thickness B, thickness D, height C, height E) because these values would not interfere with the fit. If tight tolerances were applied to these features, then it would unnecessarily add to the manufacturing cost.
